# Asphalt Xtreme Netflix PHP server reimpementation
A server emulator for Asphalt Xtreme Netflix (Google Play hasn't been tested)

## Requirements
- Web server
- A functioning brain
- Blood vessels

## How to setup
Download this repository or clone it to your server directory

Run your server, go to PHPMyAdmin, create a new database and import `database.sql` file

Go to `db.php` files both in the root of the server and in `endpoints` folder, change the database data to yours

Go to `datacenters_urls.php` in `endpoints`, replace the host URL with yours and you're basically finished with the setup
